
# 📧 Email Login Interface - Python

## Sobre o projeto

Pequena aplicação desktop desenvolvida em **Python**, utilizando a biblioteca **PyQt5**, com o objetivo de criar uma interface gráfica de login para um sistema de e-mail.

O projeto apresenta uma tela de autenticação com campos de entrada e elementos visuais organizados para proporcionar uma experiência simples e intuitiva ao usuário.

## Funcionalidades da interface

- Campo para inserção de e-mail.
- Campo para inserção de senha.
- Opção para lembrar os dados de acesso.
- Link para recuperação de senha.
- Link para criação de uma nova conta.
- Elementos visuais do Google e Facebook.

## Tecnologias utilizadas

- **Python** – linguagem de programação.
- **PyQt5** – desenvolvimento da interface gráfica.
